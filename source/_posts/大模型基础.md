## 大模型生成回答的工作原理

大模型首先在互联网上的大量语料中进行学习，学习到了词与词之间的关联。

然后拿着用户的信息，根据之前的学习，去推断概率最大的下一个词是什么，把这个概率最大的词取出拼接到用户的信息中，再根据这个拼接的信息继续推断概率最大的下一个词是什么，就这样不断循环，一个词一个词地生成，直到推断出结束符，回答完成。

控制大模型选词的参数

temperature（0~2）：温度，控制输出的发散程度。可以想象成分子，温度越低越稳定，选词的时候优先选概率最大的；温度越高越不温度，选词的时候有可能选到概率小的。

top_p：在前几个累积概率为p的词中选。

对稳定性要求高的任务，温度调低，创意性发散性的任务，温度调高。

## 大模型的调用

大模型运行在各大厂商的服务器中，通过API给用户提供大模型服务。

用户把给大模型的内容写在json中，以HTTP的方式请求调用厂商的大模型。

厂商的大模型同样把回答的内容写在json中，以HTTP的方式返回给用户。

手动写HTTP太麻烦了，已经有现成的组件封装好了调用的方法。

> python中通过API调用一次大模型的代码:

```python
from openai import OpenAI

client = OpenAI(api_key="sk-...", base_url="https://api.deepseek.com")

response = client.chat.completions.create(
    model="deepseek-v4-flash",
    messages=[
        {"role": "system", "content": "你是一个简洁直接的中文助手。"},
        {"role": "user", "content": "用一句话解释什么是递归"},
    ],
)
print(response.choices[0].message.content)
```

> 接收到的模型返回的结果:

```json
{
  "choices": [{
    "message": {"role": "assistant", "content": "递归就是……"},
    "finish_reason": "stop"
  }],
  "usage": {"prompt_tokens": 11, "completion_tokens": 24, "total_tokens": 35}
}
```

## 大模型对话中的四种角色

| role      | 代表的含义         |
| --------- | ------------------ |
| system    | 模型需要遵守的规则 |
| user      | 用户的话           |
| assistant | 模型的话           |
| tool      | 工具调用的参数     |

## 大模型的记忆

大模型是没有记忆的，只把当前的最新一条消息给大模型，大模型就只能看到这条消息，看不到过去的消息。

所以把历史对话的所有消息一并发送给大模型，大模型就可以看到所有的消息，就像有了记忆一样。

## 大模型的几点限制

上下文窗口有限：把历史对话的所有消息一并发送给大模型，大模型就可以看到所有的消息，就像有了记忆一样，但大模型一次性接收的消息的长度是有限制的，超了直接报错。

开销大花费高：大模型一个词一个词地生成，每次推断的时候，都要重新看一遍已有的信息，代价太大。KV cache，就是把不变的前缀信息缓存下来，这样就不需要每次都重新看，只看新增的部分就可以了，可以降低开销。

存在幻觉：大模型的原理是根据当前信息，推断概率最大的下一个词是什么，所以生成的信息是概率上最大的，不一定是正确的，大模型会编造误以为是正确的答案，这就是幻觉。

## 控制大模型生成的文本质量（prompt 工程）

1.system prompt 给大模型制定规则。

2.给几个输出示例，比文字描述更好。

3.结构化输出，要模型输出 JSON 时，用 API 的 `response_format={"type": "json_object"}`，比在 prompt 里喊"请务必输出合法 JSON"可靠。

### 实验源码

```python
from openai import OpenAI
import os
import sys
from pathlib import Path

SYSTEM_PROMPT = "回答要简洁明了，不要太啰嗦。"
# 测试系统提示词的影响
# SYSTEM_PROMPT = "使用文言文回答"

MODEL = "Qwen3.8-Flash-Next"
# 改成你对应服务商的base_url
BASE_URL = ""


def load_api_key() -> str:
    # 优先读取环境变量
    env_key = os.environ.get("DEEPSEEK_API_KEY")
    if env_key:
        return env_key.strip()

    # 尝试读取.env（优先当前目录，备选上级目录）
    env_paths = [
        Path.cwd() / ".env",
        Path(__file__).resolve().parent / ".env",
        Path(__file__).resolve().parents[1] / ".env",
    ]
    for env_file in env_paths:
        if env_file.exists():
            try:
                lines = env_file.read_text(encoding="utf-8").splitlines()
                for line in lines:
                    line = line.strip()
                    if not line or line.startswith("#"):
                        continue
                    if line.startswith("DEEPSEEK_API_KEY="):
                        return line.split("=", 1)[1].strip()
            except Exception as e:
                print(f"读取 {env_file} 失败: {e}", file=sys.stderr)

    sys.exit("错误：没有找到 DEEPSEEK_API_KEY。请配置环境变量或在.env中填写。")


def chat_stream(client: OpenAI, messages: list):

    """流式对话，返回完整回复文本"""
    reply = ""
    try:
        # `stream` 是一个迭代器，阻塞等待服务端推送 chunk。
        stream = client.chat.completions.create(
            model=MODEL,
            messages=messages,
            stream=True,
            temperature=0
        )
        for chunk in stream:
            # print(f"\n[DEBUG CHUNK] {chunk}", file=sys.stderr)
            if not chunk.choices:
                continue
            delta = chunk.choices[0].delta
            if delta and delta.content:
                # end="" 参数确保不换行，flush=True 立即输出到终端
                print(delta.content, end="", flush=True)
                reply += delta.content
        return reply
    except Exception as e:
        print(f"\nAPI调用异常: {e}", file=sys.stderr)
        return ""


def main() -> None:
    api_key = load_api_key()
    client = OpenAI(api_key=api_key, base_url=BASE_URL)

    messages = [{"role": "system", "content": SYSTEM_PROMPT}]
    print(f"MiniAgent v0.1（{MODEL}）")
    print("输入 exit 退出，输入 clear 清空对话历史\n")

    while True:
        # 测试大模型记忆能力
        # messages = [{"role": "system", "content": SYSTEM_PROMPT}]
        user_input = input("你> ").strip()
        if user_input == "exit":
            break
        if user_input == "clear":
            messages = [{"role": "system", "content": SYSTEM_PROMPT}]
            print("对话已清空\n")
            continue
        if not user_input:
            continue

        messages.append({"role": "user", "content": user_input})
        print("MiniAgent> ", end="", flush=True)
        reply = chat_stream(client, messages)
        print()  # 换行
        # 追加assistant回复，维持上下文记忆
        messages.append({"role": "assistant", "content": reply})



if __name__ == "__main__":
    main()

```
